### 加载后不再改写窗口几何 / async 加载泵事件 / reload 实测（US-008 起）
- **全仓仅 2 个 `ApplyPositionAndResolution()` 调用点**：`F3DStarter::Start` 内 :1444（建引擎后，首次）与 :1498（`LoadFileGroup()` 后，第二次）。window `setSize`/`setPosition` 仅出现在 `ApplyPositionAndResolution`/`ApplyDefaultCenteredGeometry` 内（`cam.setPosition` 是相机非窗口）；`LoadFileGroup`/`LoadFileGroupInternal`/render/相机 reset/`EventLoop` 均不碰窗口几何。故第二次调用是冗余、对 --output **无时序依赖**（实证：git stash 改前二进制重编，改前/改后 --output 产物 SHA256 **逐字节相同**）。
- **守卫式去重**：加 `Internals::GeometryEstablished`（bool，默认 false），在 `ApplyPositionAndResolution` 顶部（NoRender 早退后）置 true；第二调用点 `if(GeometryEstablished) log("skip geometry re-apply: already established") else ApplyPositionAndResolution()`。渲染路径第一调用恒先跑→else 是防御性死码。offscreen 也置 true→第二次同样 skip（输出逐字节不变，安全）。**US-007 持久化恢复应在第一次 ApplyPositionAndResolution 内落地**（几何单点建立），别再引第三处改写窗口几何。

### wasm 构建：worktree 干净 shell 里 emsdk 自激活失效（US-005 复现）

### 窗口几何跨会话持久化（US-007 起）
- **落点分层**：新 app 模块 `application/G3DWindowState.{h,cxx}`（G3D 品牌命名）= 纯/IO 构件（状态文件路径解析+env 开关、原子 JSON load/save、rect 对显示器工作区的有效性校验+clamp）；`application/G3DWindowGeometry` 增 `allMonitorWorkAreas()`（Win32 `EnumDisplayMonitors`+`GetMonitorInfoW`，**非捕获 lambda** 才能转 `MONITORENUMPROC`，输出向量走 LPARAM）；**save/restore 策略（防抖/抑制/退出兜底）留在 `F3DStarter`**，且**恢复在第一次 `ApplyPositionAndResolution` 内单点落地**（承 US-008：几何单点建立，不引第三处改写窗口几何）。

- **状态文件**：Windows `%LOCALAPPDATA%\Glance3D\window-state.json`（**与日志同根** = `F3DSystemTools::GetUserCacheDirectory()`，但 US-007 用 `stateDirectory()` 自解析：Linux `$XDG_STATE_HOME`|`~/.local/state/Glance3D`、macOS `~/Library/Application Support/Glance3D`——**state ≠ cache**，别复用 GetUserCacheDirectory 的跨平台分支）。JSON `{version,x,y,width,height,maximized}`，**物理像素、不做跨会话 DPI 换算**（FR-17，靠校验兜底）。原子写 = 同目录 `.tmp` + `fs::rename`（MSVC/POSIX 均替换既存）。
- **存的是「普通 rect + maximized 位」而非最大化 bounds**：app 层无 `GetWindowPlacement.rcNormalPosition`，故 `Internals::LastNormalGeometry` 跟踪**本会话最后一次非最大化 rect**（每次 `isMaximized()==false` 时更新为 `getPosition()+getWidth/Height()`），最大化时用它+`maximized=true` 落盘；恢复时先 `setSize/setPosition(普通 rect)` 再 `setMaximized(true)`（先定位后最大化，落对显示器）。实证：最大化后 relaunch，`GetWindowPlacement` showCmd=3 且 **rcNormal 逐字还原**（普通 rect 无损，取消最大化回到原窗）。**坑**：`getPosition` 返 outer top-left、`getWidth/Height` 返 **client** 尺寸→存的 width/height 是 client（比 MoveWindow 的 outer 少 frame 16×39@dpi1）；但恢复 `setPosition(outer x,y)`+`setSize(client)`→`GetWindowRect` **outer 逐位还原**（client+frame=outer），三方对齐按 outer 比。
- **防抖保存 + 退出兜底**：`EventLoop`（VTK `CreateRepeatingTimer` 每 ~33ms 恒触发，**与有无输入无关**，interactor_impl.cxx:586）里每 tick `MaybeSaveWindowState(false)`——poll 当前几何，变了就更 Pending+重置 `steady_clock` 计时，dirty 且距上次变更 ≥1s 才写（几何稳定后才存）。`interactor.start()` 返回后 `MaybeSaveWindowState(true)` **兜底 flush**：**force 分支不 re-read 窗口**（窗口可能正被销毁），只 flush 最后一次 live tick 捕获的 PendingState（≤33ms 前，安全且够准）。实证：MoveWindow 后 250ms 内 WM_CLOSE（<1s 防抖窗）→退出 flush 存下移动后的几何。
- **抑制 = source-based**（复用 US-006 的 `OptionExplicitlyProvided`）：`--output/--reference/--list-bindings`(offscreen)、`--resolution`、`--position`、`--no-config`(存 `Internals::NoConfig`)任一 → `WindowStateActive=false`、**既不恢复也不保存**（实测 state 文件 mtime+内容不变）；`--no-render` 天然免疫（NoRender 时 `ApplyPositionAndResolution` 根本不被调）。所有既有 recordings 带 `--no-config --resolution=300,300` → 双重抑制，误差与 US-006/008 既往值**逐位相同**（0.120849/0.097272/0.095841）证零影响。
- **开关/校验**：`G3D_WINDOW_STATE=0` 禁用（`resolveStateFilePath`→nullopt→`suppressed(disabled)`）、`=<path>` 重定向（**测试隔离必用**，别污染真 `%LOCALAPPDATA%`）。有效性校验 `validate()`：与某显示器工作区交集 ≥100×100 + 标题栏可达（top edge 在 `[work.y-40, work.y+work.h-30]`）→ clamp size 到该屏；空 workAreas（非 Windows 无枚举）**fail closed**→nullopt→回退默认居中。损坏 JSON→`load()` 返 Corrupt→WARN+`restore-invalid(corrupt)`+默认居中，不崩。
- **决策日志原因码**（都带 `Window geometry: reason=` 前缀，file log 恒抓 DEBUG）：`restored`/`restore-invalid`[`(corrupt)`]/`default-centered`/`suppressed(<offscreen|resolution|position|no-config|disabled>)`/`saved`。端到端三方对齐（state 文件 ↔ 日志 restored ↔ `GetWindowRect`）已实测 `OUTER_RECT_ROUNDTRIP_MATCH=True`。
- **坑：新 .h 里别用 em-dash「—」等非 ASCII**——MSVC codepage 936 下报 **C4819**，`/WX` 直接 fatal（`file` 命令查 `UTF-8 text` 即有非 ASCII；改 ASCII `-`）。dev-strict 单文件 /W4 /WX 复用 US-009 隔离法：G3DWindowState.cxx/G3DWindowGeometry.cxx/F3DStarter.cxx（app vcxproj）、window_impl.cxx（libf3d vcxproj）各 EXITCODE=0；**MSBuild 单文件必用 PowerShell `& $msbuild`**（bash 传参报 MSB1008「只能指定一个项目」）；改 CMake 加了新源文件须先 `cmake --preset dev-local` 重配 vcxproj 才能单文件编它。
